Hi everyone.
I'd like to write some articles about mathematics in Lojban.
I'd be happy to hear feedback about these.

I'll be using {jo} for if X then Y and {jo'o} for X iff Y.

Today I'll talk about monoids.  A monoid is a set A together
with a multiplication operator and a unit.  A monoid must
satisfy that x times the unit and the unit times x must both
be x again, and x times y times z must work out the same way
however you put the parentheses.

The natural numbers are a monoid by taking the usual
multiplication and taking 1 as the unit.

If e1 and e2 are both units, then they are equal.  The proof
is as follows:
e1 = e1 times e2 = e2.
The first equality holds because e2 is a unit, and the
second because e1 is a unit.
