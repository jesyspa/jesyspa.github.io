title: Excluded middle in everyday life
---

Plan:

* Every function we can compute/measure is continuous
* In particular, every function that depends on time is
  continuous, and every predicate that was once false and is
  now true thus witnesses a continuous path false -> true.
* Ergo, we do not in general speak of absolute truth: truth
  is but an approximation
* This violates/refutes LEM.  LEM is not a valid reasoning
  principle in a setting like this.
* Any project that requires absolute certainty is thus
  self-defeating, since certainty cannot be achieved.
* "True" and "false" are still useful approximations.
